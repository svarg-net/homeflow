# 👨‍👩‍👧‍👦 homeflow — Семейный Ассистент

Кроссплатформенное приложение для управления семейным бюджетом, списками дел и совместными покупками с мгновенной синхронизацией между устройствами.

## 🚀 Основные фичи
* **Управление финансами**: Раздельные и общие счета. Настраиваемый статус счета: «участвует в общем бюджете» или является «личным».
* **Списки запланированных покупок**: Создание списков с указанием запланированного бюджета и фиксацией фактических трат.
* **Семейный список дел**: Общие To-Do списки задач с распределением зон ответственности.
* **Уведомления в мессенджеры**: Интеграция с Telegram и ВКонтакте (VK) для отправки важных уведомлений и отчетов.
* **Offline-first на мобильных**: Возможность полноценно использовать списки покупок и дел в супермаркетах даже при отсутствии интернета.

## 🛠 Стек технологий (Актуальность: 2026)

### Бэкенд (`/backend`)
* **Язык/Фреймворк**: PHP 8.5 + Laravel 13.x (API Mode)
* **Рантайм-сервер**: Laravel Octane + RoadRunner v3.x (Высокопроизводительный Go-сервер приложений)
* **База данных**: PostgreSQL 18
* **Кэш и Очереди**: Redis 8.x (Мгновенная обработка задач мессенджеров и кэширование балансов)
* **Синхронизация (Real-time)**: Laravel Reverb (Встроенный WebSocket-сервер)

### Веб и Десктоп (`/frontend-desktop`)
* **Фреймворк**: Vue 3.5+ (Composition API) + Vite + Pinia (Стейт-менеджер)
* **Десктопная оболочка**: Tauri 2.x (Легковесная альтернатива Electron на Rust)
* **Стилизация**: Tailwind CSS

### Мобильное приложение (`/mobile`)
* **Фреймворк**: Flutter 3.x + Dart 3.x
* **Локальная БД (Offline-mode)**: Isar / Hive для кэширования и очереди офлайн-мутаций

## 💻 Локальное развертывание (Development)

### 1. Бэкенд (в Docker)
Для работы бэкенда не нужно устанавливать PHP локально — всё упаковано в контейнеры.

```bash
cd backend
cp .env.example .env
docker compose up -d --build
```
Бэкенд запустит 4 контейнера: `app` (API и WebSockets), `db` (PostgreSQL 18), `redis` (Redis 8.x) и `queue` (воркер очередей).
* **API URL**: `http://localhost:8000`
* **WebSocket URL**: `ws://localhost:8080`

Выполните миграции внутри контейнера:
```bash
docker compose exec app php artisan migrate
```

### 2. Веб и Десктоп (Локально)
Убедитесь, что у вас установлена Node.js 22 LTS и компилятор Rust (для Tauri).

```bash
cd frontend-desktop
npm install

# Запуск веб-версии в браузере
npm run dev

# Запуск десктопного приложения (Tauri)
npm run tauri dev
```

### 3. Мобильное приложение (Локально)
Требуется установленный Flutter SDK, Android Studio / Xcode и запущенный эмулятор.

```bash
cd mobile
flutter pub get
flutter run
```

## 🌐 Деплой и Инфраструктура (`/deploy`)

Проект подготовлен для автоматического деплоя на виртуальный сервер (VPS) с помощью GitHub Actions и Docker Compose.

В папке `/deploy/production` находятся конфигурационные файлы для боевого окружения:
* **`docker-compose.prod.yml`**: Оптимизированные production-контейнеры (без папок разработки, с включенным кэшированием OPcache в PHP 8.5 и production-конфигом для Redis 8.x).
* **`nginx.conf`**: Настройки Nginx в качестве Reverse Proxy для проксирования HTTP к RoadRunner, WebSockets к Laravel Reverb и раздачи статики Vue-приложения.

### CI/CD автоматизация
При каждом `git push` в ветку `main` запускается пайплайн `.github/workflows/deploy.yml`, который:
1. Подключается к серверу через безопасный SSH-тоннель.
2. Скачивает свежую версию кода.
3. Собирает production-образы.
4. Выполняет миграции базы данных и кэширование конфигурации Laravel.
5. Мягко перезапускает воркеры RoadRunner с помощью команды `rr reset`.

Для работы деплоя необходимо добавить в **GitHub Repository Secrets**:
* `SERVER_HOST` — IP-адрес сервера.
* `SERVER_USER` — Логин пользователя (например, `root`).
* `SERVER_SSH_KEY` — Ваш приватный SSH-ключ.

## 🔒 Безопасность и Архитектура данных
* **Авторизация**: Реализована через токены (Laravel Sanctum). Каждая семья изолирована на уровне базы данных (`family_id`).
* **Логика бюджетов**: Общий баланс семьи рассчитывается динамически на основе счетов, у которых флаг `is_included_in_total_budget = true`.
